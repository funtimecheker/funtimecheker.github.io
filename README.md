# FunTime Checker — промосайт проекта

Профессиональный одностраничный сайт утилиты **FunTime Checker** для проверяющих и модераторов FunTime.

Дизайн построен на полностью чёрной основе с глубоким бордовым акцентом `#9B0B26`, спокойной белой типографикой и минимальным количеством системных цветов. Тексты объясняют пользу продукта человеческим языком, а технические детали остаются внутри интерфейса демо.

## Что реализовано

- вступительная анимация и кинетическая типографика;
- интерактивный экран проверки в hero-блоке;
- живой поиск по демонстрационным результатам;
- карточки с объёмом, бликами и реакцией на курсор;
- переключаемые зоны проверки;
- анимированный сценарий из трёх шагов;
- пример готового отчёта и раскрывающийся FAQ;
- адаптивная версия от 320 px;
- поддержка `prefers-reduced-motion`;
- адаптивное качество canvas: 60 FPS на desktop и облегчённый режим на мобильных;
- автоматическая пауза циклических эффектов вне экрана;
- локально подключённые шрифты без внешних запросов;
- локальная работа без библиотек и сборки.

## Структура

```text
index.html        — разметка и контент
assets/style.css  — дизайн, адаптивность и анимации
assets/app.js     — интерактивность и визуальные эффекты
.nojekyll         — совместимость со статическими хостингами
```

## Локальный запуск

Можно открыть `index.html` напрямую или запустить статический сервер:

```bash
python -m http.server 8080
```

После этого сайт доступен по адресу `http://localhost:8080`.

## Деплой

Проект не требует сборки и подходит для Cloudflare Pages, Netlify, Vercel или обычного nginx.
